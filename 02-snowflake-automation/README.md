# Snowflake Automation

**Goal:** Automate ingestion from S3 to Snowflake using Snowpipe and orchestrate downstream transforms with Airflow.

**Highlights**
- Snowpipe for near real-time loads
- Airflow DAG triggers model refresh and validation
- Example test query to validate daily loads

**Tech:** Snowflake, Snowpipe, S3, Airflow, SQL, Python
